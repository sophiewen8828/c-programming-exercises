Interactive judges

Practice sites — solve, submit, get judged

Online judges give instant feedback and let you compare your solution with others after it passes — the fastest feedback loop for improving in a short period. Solve in C even when other languages are offered.

SiteBest forWhy it fits
Exercism — C track Structured ramp-up Free, ~120 small-to-large exercises with human mentoring and code review. The gentlest structured start.
LeetCode Topic drilling Huge problem bank; filter by topic (arrays, strings, linked lists, trees) and difficulty.
HackerRank — C track Daily volume Gentle intro track, then algorithm domains for steady daily practice.
Codeforces Rated practice Timed contests and problems rated 800–3500, so you can always pick your exact level.
SPOJ / UVa Online Judge Classic volume Thousands of classic problems; UVa is the judge behind Taiwan's CPE exam.
CodinGame Fun practice Write C code that plays games — makes daily practice feel like play.
Project Euler Numeric C skills Math-flavoured problems that exercise integer handling and overflow reasoning.
Advent of Code Seasonal streaks 25 puzzles every December; past years stay online — do them all in C.

Tip. Always compile with gcc -std=c11 -Wall -Wextra -Werror while practising, even on sites that accept looser code. Warnings are free lessons.

Short-period improvement

A realistic four-week plan

The single biggest lever is daily consistency plus always reading someone else's solution after your own works. Two months of that visibly changes your C fluency; four focused weeks already moves you a level.

  1. Volume

    Solve two easy problems a day on Exercism or Codeforces (rated ≤ 1000). Always compile with gcc -std=c11 -Wall -Wextra -Werror.

  2. Data structures from scratch

    Write your own dynamic array, hash map, linked list, and binary heap in C, each with a test harness — reuse this repository's run_tests.sh pattern.

  3. Medium problems

    Move to LeetCode or UVa medium-tier problems in your weakest topics. After each solve, read the top-ranked solution and note what it does better.

  4. A real project

    Build the kilo text editor or the SQLite-clone tutorial end to end. Pointers, malloc discipline, and struct design finally cement here.

Progress rule. A problem counts as solved only when your program passes every test and you can explain its invariants out loud without reading the code — the same standard this repository's study guide uses.
