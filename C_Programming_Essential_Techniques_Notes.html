C 語言經典習題必要技巧
學習重點筆記

對應「Five Classic C Programming Exercises」五道經典題目

一、前言

本筆記整理解決以下五道經典 C 語言習題時，最核心且反覆出現的技巧、語法與演算法思維：

  1. 帶狀矩陣乘法（Banded Matrix Multiplication）
  2. 約瑟夫問題（Josephus Problem）
  3. 括號平衡判斷（Balanced Parentheses）
  4. 螺旋矩陣遍歷（Spiral Matrix Traversal）
  5. 樹的廣度優先探索（Tree Exploration）
學習目標： 不只會寫出能過測資的程式，更能理解「為什麼這樣設計」，並能自行推導正確性與處理邊界情況。

二、基礎必備技能

以下是進入這五題前應已熟練的基礎：

  • 變數、算術運算、條件判斷（if）與迴圈（for / while）
  • 函式的定義與呼叫
  • 一維與二維陣列的宣告、初始化與存取
  • 基本指標語法（雖本系列題目較少直接使用）
  • scanf、printf、fgets、putchar 的使用
  • 編譯時開啟警告：gcc -std=c11 -Wall -Wextra

三、精確輸入輸出控制

這是最容易因為「看起來正確卻測不過」而失分的地方。

1. 輸入檢查

if (scanf("%d %d", &n, &m) != 2)
    return 0;

務必檢查 scanf 的回傳值，確保成功讀取預期數量的資料。

2. 輸出格式嚴格要求

  • 數字之間只能有一個空格，最後一個數字後不能有空格。
  • 推薦寫法：
for (int i = 0; i < count; i++) {
    if (i > 0) putchar(' ');
    printf("%d", arr[i]);
}
putchar('\n');

3. 特殊格式：%04d

printf("%04d", value);
  • 寬度包含負號：-24 會印成 -024，而不是 -0024。
  • 正數會補前導零，例如 38 → 0038。

4. 讀取一行字串

char line[MAXLEN + 2];
if (fgets(line, sizeof(line), stdin) == NULL)
    return 0;

// 處理時跳過 '\n' 與 '\r'
for (int i = 0; line[i] != '\0' && line[i] != '\n' && line[i] != '\r'; i++) {
    // ...
}
重要禁忌： 絕對不要印出任何提示訊息（例如 Enter N:），也不要在正式輸出中混入除錯用的 printf。除錯訊息請輸出到 stderr。

四、陣列操作與邊界處理

1. 固定大小陣列

int A[20][20] = {0};   // 全部初始化為 0
int dist[101];         // 一維陣列

2. 邊界夾逼（Clamping）

int lo = i - p;
int hi = i + q;

if (j - s > lo) lo = j - s;
if (j + r < hi) hi = j + r;
if (lo < 0)     lo = 0;
if (hi > n - 1) hi = n - 1;

這是帶狀矩陣乘法中計算有效 k 範圍的核心技巧。

3. 0-based 與 1-based 的轉換

  • 陣列索引通常使用 0-based。
  • 題目若要求 1-based 輸出，只在最後轉換一次。
  • 圖的節點若編號為 1～N，陣列大小需開到 N+1。

五、堆疊（Stack）模擬

適用於括號匹配、巢狀結構等「後進先出」問題。

char stack[MAXLEN + 1];
int top = 0;

// Push
stack[top++] = c;

// Pop / 檢查匹配
if (top == 0 || stack[top - 1] != want) {
    ok = 0;          // 失敗
} else {
    top--;           // 成功彈出
}

// 最終檢查
if (top != 0) ok = 0;  // 還有未閉合的左括號
核心不變量： 堆疊中保存的是「目前尚未匹配的左括號」，且由底到頂依開啟順序排列。任何右括號都必須與棧頂匹配。

六、佇列（Queue）與廣度優先搜尋（BFS）

int queue[MAXN];
int head = 0, tail = 0;
int dist[MAXN + 1];

// 初始化
for (int i = 1; i <= n; i++) dist[i] = -1;
dist[1] = 0;
queue[tail++] = 1;

// BFS
while (head < tail) {
    int u = queue[head++];
    for (int v = 1; v <= n; v++) {
        if (adj[u][v] && dist[v] == -1) {
            dist[v] = dist[u] + 1;
            queue[tail++] = v;
        }
    }
}

重點：

  • 用陣列模擬佇列，head 與 tail 指標即可。
  • dist[] 同時扮演「是否造訪過」與「距離」的角色。
  • 樹或圖的遍歷順序若有額外要求（例如同層依編號排序），需在 BFS 後再額外排序。

七、邊界模擬（螺旋矩陣核心技巧）

使用四個邊界變數描述「尚未走訪的矩形區域」：

int top = 0, bottom = n - 1;
int left = 0, right = m - 1;

while (top <= bottom && left <= right) {
    // 1. 上邊：左 → 右
    for (int j = left; j <= right; j++)
        emit(a[top][j]);
    top++;

    // 2. 右邊：上 → 下
    for (int i = top; i <= bottom; i++)
        emit(a[i][right]);
    right--;

    // 3. 下邊：右 → 左（需守衛）
    if (top <= bottom) {
        for (int j = right; j >= left; j--)
            emit(a[bottom][j]);
        bottom--;
    }

    // 4. 左邊：下 → 上（需守衛）
    if (left <= right) {
        for (int i = bottom; i >= top; i--)
            emit(a[i][left]);
        left++;
    }
}
經典陷阱： 當矩陣退化成單行或單列時，若沒有第三、第四步的守衛條件，會造成重複輸出。務必加上 if (top <= bottom) 與 if (left <= right)。

八、數學遞迴與模運算（約瑟夫問題）

避免直接模擬圓形淘汰，改用遞迴關係：

int survivor = 0;          // 0-based 位置
for (int i = 2; i <= n; i++)
    survivor = (survivor + k) % i;

printf("%d\n", survivor + 1);  // 轉成 1-based

對應的數學關係：

J(1) = 0
J(n) = (J(n-1) + K) mod n
優點： 時間複雜度 O(N)、空間 O(1)，且程式極為精簡，不容易出錯。

九、圖的表示與特殊輸入解析

1. 鄰接矩陣

int adj[MAXN + 1][MAXN + 1] = {0};
adj[a][b] = 1;
adj[b][a] = 1;   // 無向圖

2. 解析特殊格式輸入（例如 {a,b}）

int a, b;
if (scanf(" { %d , %d }", &a, &b) != 2)
    return 0;

格式字串中的空白可以幫助跳過換行與多餘空白字元。

3. 排序（距離優先，編號次之）

可使用插入排序實作：

// 依 (dist[v], v) 遞增排序
for (int i = 1; i < count; i++) {
    int key = order[i];
    int j = i - 1;
    while (j >= 0 &&
           (dist[order[j]] > dist[key] ||
            (dist[order[j]] == dist[key] && order[j] > key))) {
        order[j + 1] = order[j];
        j--;
    }
    order[j + 1] = key;
}

十、五題技巧對應地圖

1. 帶狀矩陣乘法 二維陣列、邊界夾逼、%04d 格式、精確空格控制
2. 約瑟夫問題 模運算、0/1-based 轉換、數學遞迴思維
3. 括號平衡 陣列模擬堆疊、fgets 讀取、字元匹配

十一、常見陷阱與除錯建議

症狀 可能原因 建議解法
只差在最後多一個空格 空格印在每個元素後面 改為「非第一個元素前先印空格」
-24 印成錯誤格式 對 %04d 理解錯誤 記住負號也佔寬度
螺旋矩陣重複輸出 缺少第三、四邊守衛 加上 top ≤ bottom 與 left ≤ right 判斷
括號判斷錯誤 只用計數而未考慮順序 必須使用堆疊
樹遍歷順序錯誤 只依發現順序輸出 BFS 後依 (距離, 編號) 排序
N=1 或單行/單列錯誤 未處理退化情況 務必測試最小邊界
除錯習慣建議：
  1. 先用最小能重現錯誤的測資進行思考。
  2. 手動模擬變數變化，預測下一輪結果再比對。
  3. 編譯時加上 -fsanitize=address,undefined 捕捉越界與未定義行為。
  4. 對於小規模輸入，可寫暴力版本作為對照（oracle）。

十二、學習建議

  1. 先自己實作：看完題目後先嘗試 45～90 分鐘，再對照參考解法。
  2. 比較設計而非只比答案：思考自己的方法與參考方法在時間、空間、可讀性上的差異。
  3. 主動製造邊界測資：N=1、單行、單列、最大規模、負數、特殊格式等都要自己試。
  4. 記錄錯誤：把踩過的坑與最小重現輸入寫下來，這是最有效的進步方式。
  5. 能講清楚正確性：一個解法真正完成的標準，是你能不看程式碼就向別人解釋「為什麼它是對的」。
總結： 這五題看似不同，但背後共用的核心能力其實不多——精確 I/O、陣列邊界、堆疊/佇列模擬、邊界收縮、數學化簡、以及清楚的不變量思維。把這些技巧練熟後，許多其他演算法題目都會變得親切許多。
